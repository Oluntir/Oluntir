# First start

1. Extract Oluntir 1.2.0 into its own folder.
2. Open `index.html` in a current desktop browser.
3. Choose **Single monitor**, **Two monitors**, or keep the startup question enabled.
4. Create a project or restore a portable `.oluntir` backup.
5. Before major work, verify project saving and create an external backup.

## Browser permissions

Folder access, pop-ups, and display placement are browser-controlled. Grant only the permissions required for the current project. If the tool window is blocked, keep working in single-monitor mode and reopen it from the toolbar after allowing pop-ups.

## Project folder

The Image Manager can connect to a physical project folder. Select the project root. Oluntir automatically uses or creates `assets/user_upload/`; do not select that subfolder directly.
