# Oluntir 1.2.0

Oluntir 1.2.0 introduces a stable two-monitor workspace, a workspace-based Image Manager with guided project-folder connection, and clearly separated Modal and Lightbox gallery viewers.

## Highlights

- Move the complete right GrapesJS tool column and Oluntir quick editing to a second window.
- Persistent monitor preferences with safe one-monitor fallback and window recall.
- Searchable Image Manager with grid/list views, variants, details, replacement, deletion safeguards, and `assets/user_upload/` synchronization.
- True dark Lightbox and framed Modal, both with captions, counters, keyboard operation, original download, and bottom safe area.
- Unchanged, versioned GrapesJS vendor dependency behind an explicit compatibility adapter.

## Upgrade

Extract the release into a new folder. Keep the previous version and a project backup until opening, editing, saving, and exporting have been verified.

## Notes

Browser permissions govern folder access, pop-ups, and automatic placement on another display. Oluntir falls back safely when these capabilities are unavailable.
