# Schnellbearbeitung

## Zweck

Die Schnellbearbeitung stellt häufig benötigte Eigenschaften ausgewählter Seitenelemente in einem separaten Dialog bereit.

## Unterstützte Elemente

- Buttons;
- Überschriften;
- Textabsätze;
- Bilder;
- Karten und weitere unterstützte Komponenten.

## Verhalten

Änderungen werden auf das aktuell ausgewählte Element angewendet. Nicht unterstützte Elemente verwenden weiterhin die regulären Editorwerkzeuge.

## Test

Element auswählen, Werte ändern, übernehmen und anschließend Vorschau, Speicherung und Export prüfen.
