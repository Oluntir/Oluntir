# Blocksuche

## Zweck

Die Blocksuche filtert die im Editor verfügbaren Inhaltsblöcke.

## Bedienung

Ein Suchbegriff reduziert die sichtbare Blockliste anhand von Name und hinterlegten Suchbegriffen. Das Leeren des Suchfelds stellt die vollständige Liste wieder her.

## Test

- Suche nach vollständigen und teilweisen Begriffen;
- Wechsel zwischen Bootstrap-Profilen;
- Zurücksetzen des Suchfelds;
- Tastaturfokus und Bedienung im rechten Panel.
