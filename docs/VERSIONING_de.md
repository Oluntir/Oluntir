# Versionierung und Release-Sprache

Oluntir orientiert sich, soweit praktisch möglich, an Semantic Versioning:

- **Major:** inkompatible Änderungen an Architektur, Projektformat oder Arbeitsweise;
- **Minor:** abwärtskompatible Funktionen und umfangreiche Verbesserungen;
- **Patch:** abwärtskompatible Fehlerbehebungen, Dokumentationskorrekturen und Wartung.

Jede stabile Version soll gleichwertige englische und deutsche Release-Informationen im Repository und in der GitHub-Releasebeschreibung enthalten. Beide Sprachversionen werden als eigenständige Dokumentation gepflegt; keine Fassung soll eine ungeprüfte Maschinenübersetzung sein.

Release-Artefakte verwenden die Form `Oluntir_<Major>.<Minor>.<Patch>_FINAL.zip` und sollen von einer SHA-256-Prüfsumme begleitet werden.
