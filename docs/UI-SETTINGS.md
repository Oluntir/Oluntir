# UI Settings

**Version:** 1.0.0  
**Language:** English  
**Status:** Stable  
**Applies to:** Oluntir 1.0.0  
**Last updated:** 2026-07-29

## Purpose

Documents local user-interface settings such as language and display preferences. UI settings are separate from website project content and should not alter exported output unless explicitly defined.

## Scope

This document describes the behavior included in Oluntir 1.0.0.

## Verification

Test the function with a newly created project and a restored project. Where export is affected, test folder and archive output and compare the generated file structure with the selected format.

## Limitations

Browser capabilities and imported project content may affect behavior. Report reproducible deviations with the browser version, project type, steps, and console output.
