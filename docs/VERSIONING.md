# Versioning and release language

Oluntir follows Semantic Versioning where practical:

- **Major:** incompatible architecture, project-format, or workflow changes;
- **Minor:** backward-compatible features and substantial improvements;
- **Patch:** backward-compatible fixes, documentation corrections, and maintenance.

Every stable release should provide equivalent English and German release information in the repository and in the GitHub release description. Both language versions are maintained as first-class documentation; neither should be treated as an unreviewed machine translation.

Release artifacts use the version form `Oluntir_<major>.<minor>.<patch>_FINAL.zip` and should be accompanied by a SHA-256 checksum.
