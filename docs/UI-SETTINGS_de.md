# UI-Einstellungen

## Zweck

UI-Einstellungen steuern die Darstellung der Editoroberfläche, ohne den exportierten Seiteninhalt zu verändern.

## Umfang

Je nach Version können Einstellungen für Bedienbereiche, Darstellung oder Sprache verfügbar sein. Änderungen werden im Browser gespeichert und beim nächsten Start wiederhergestellt.

## Abgrenzung

Projektinhalt, Framework-Profil und Exportformat werden nicht über die UI-Darstellungseinstellungen verändert.
