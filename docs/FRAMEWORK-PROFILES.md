# Framework Profiles

**Version:** 2.1.0 BETA
**Language:** English
**Status:** BETA
**Stable baseline:** Oluntir 1.3.1
**Last updated:** 2026-09-06

## Purpose

Framework profiles define the bundled CSS and JavaScript resources used by a project. Oluntir 2.1.0 BETA includes Bootstrap 4.6.2 and Bootstrap 5.3.8 profiles. Profiles must remain versioned and offline-capable. Unknown source packages are analysis-only.

## Scope

This document describes the behavior included in Oluntir 2.1.0 BETA.

## Verification

Test the function with a newly created project and a restored project. Where export is affected, test folder and archive output and compare the generated file structure with the selected format.

## Limitations

Browser capabilities and imported project content may affect behavior. Report reproducible deviations with the browser version, project type, steps, and console output.
