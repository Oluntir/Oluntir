# Roadmap

**Current stable version:** 1.2.0  
**Last updated:** 2026-07-30

The roadmap describes candidate work packages, not binding delivery dates.

## Completed in 1.2.0

- two-monitor workspace with persistent settings and safe fallback;
- complete relocation of the right GrapesJS tool column and Oluntir quick-edit areas;
- workspace-based Image Manager and project-folder synchronization;
- independent Modal and Lightbox gallery modes with keyboard and download controls;
- protected viewer bottom safe area;
- stronger GrapesJS adapter boundary and release documentation.

## Candidate work for 1.3.0

- automated browser smoke tests for current Chromium-based browsers and Firefox;
- clearer diagnostics for denied folder, pop-up, and window-management permissions;
- optional resizable divider in the external tool window;
- improved project migration reports and recovery preview;
- deeper accessibility review of editor dialogs and keyboard flows;
- further replacement or modernization of older bundled website plugins;
- additional image-management diagnostics and synchronization status.

## Longer-term candidates

- project explorer for pages and recurring content elements and regions;
- more reusable templates and export writers;
- optional additional framework profiles after compatibility and licensing review;
- broader automated regression coverage for imports, exports, and restored projects.

Every work package requires a defined data model, user flow, compatibility boundary, migration behavior, tests, documentation, and license review before implementation.
