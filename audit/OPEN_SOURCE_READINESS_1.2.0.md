# Open-source readiness — Oluntir 1.2.0

## Five-minute repository orientation

A new visitor can determine:

- **What it is:** an offline-first visual editor for static Bootstrap websites.
- **How it starts:** extract the package and open `index.html`.
- **What powers the canvas:** GrapesJS 0.23.2, kept unchanged as a vendor dependency.
- **What Oluntir adds:** projects, includes, export, workspaces, assets, settings, galleries, and multi-monitor behavior.
- **How to contribute:** follow `CONTRIBUTING.md` and run the documented structure and adapter tests.
- **How to report security issues:** use the confidential contact in `SECURITY.md`.
- **How it is licensed:** MIT for original code; third-party terms remain documented separately.

## Repository hygiene

- No legacy product branding was found in first-party release files.
- No temporary, backup, or editor-generated files were found.
- Intermediate development audit logs were removed.
- English reference documents and German counterparts are linked from the root documentation.
- Release notes, What's New, audit, and GitHub publication instructions match version 1.2.0.
