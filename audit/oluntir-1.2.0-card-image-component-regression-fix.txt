Oluntir 1.2.0 – Card image component regression fix

Cause:
The previous grid persistence correction called components(innerHTML) on the surrounding editable root after replacing an existing image. For card images this reparsed the complete card subtree, detached GrapesJS component bindings and allowed the raw image to render at its intrinsic dimensions.

Correction:
- Existing image replacements now update only the mapped GrapesJS image component attributes.
- The surrounding card/grid/text component tree is no longer reparsed for image replacement.
- Inline image insertion into rich text still uses the dedicated text synchronization path.
- Editable component resolution accepts only an exact GrapesJS view-to-DOM match.

Checks:
- JavaScript syntax: passed
- Structure validator: passed
- GrapesJS adapter test: passed
