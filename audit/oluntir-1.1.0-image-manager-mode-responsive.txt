Oluntir 1.1.0 Image Manager Finetuning

Implemented:
- Responsive list view with four layout stages.
- Explicit assign/manage mode detection.
- Persistent mode badge and contextual warning.
- Direct image assignment hidden and disabled in manage mode.
- Guidance to close the manager, select an image element, and reopen its image selection.
- Double-click and repeated-card selection only assign in assign mode.

Browser interaction must still be verified manually.
