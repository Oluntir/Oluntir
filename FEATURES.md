# Oluntir – Feature overview

- Local visual website editing with GrapesJS
- Bootstrap 4 and Bootstrap 5
- Multiple pages, navigation, header, and footer
- Single- and dual-monitor workspace
- Quick editing and rich-text editing
- “+ Insert section here” hint on empty new pages
- Portable `.oluntir` projects
- Stable internal layout identities and additive 1.2.0 migration
- Shared Content, OPE Includes, and Repeat Engine V2 technical foundation
- Image manager with desktop, tablet, and mobile variants
- Complete responsive image export
- Gallery, modal, and lightbox
- Project-wide favicon generation including manifest
- HTML, SSI, and PHP export to folder, ZIP, or TAR
- Read-only model-based export with local assets
