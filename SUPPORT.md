# Support

**Version:** 1.2.0  
**Language:** English  
**Status:** Stable  
**Applies to:** Oluntir 1.2.0  
**Last updated:** 2026-07-30

## Supported requests

Support covers installation, browser behavior, project creation, project restore, Oluntir recurring content elements and regions, code view, and HTML, SSI, or PHP export.

## Information to include

Provide the Oluntir version, operating system, browser and version, project type, export format and target, exact steps, expected result, actual result, and relevant console messages.

## Contact

Use the repository issue tracker for reproducible non-security defects. Send security-sensitive information according to [SECURITY.md](SECURITY.md). General project contact: `info@oluntir.com`.
