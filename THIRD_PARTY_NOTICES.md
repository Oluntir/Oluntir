# Third-party notices

**Version:** 1.1.0  
**Language:** English  
**Status:** Stable  
**Applies to:** Oluntir 1.1.0  
**Last updated:** 2026-07-29

Oluntir bundles third-party software and assets for offline operation. Each component retains its original license.

The authoritative inventory is maintained in:

- `compliance/LICENSE_MATRIX.md`;
- `compliance/ASSET_INVENTORY.md`;
- `compliance/SOURCE_ATTRIBUTION.md`;
- license texts under `LICENSES/`.

Release packages must retain these records. Component versions and file paths should be verified as part of every release license check.
