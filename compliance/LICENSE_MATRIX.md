# License Matrix

**Version:** 2.2.0 BETA
**Language:** English
**Status:** BETA
**Stable baseline:** Oluntir 1.3.1
**Last updated:** 2026-09-06

## Purpose

Maps bundled components and assets to their licenses, notice requirements, source records, and repository paths. It is used during release review.

## Release requirement

The file must be reviewed together with `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`, and the license texts under `LICENSES/`. Missing or unclear entries block release publication until resolved.

## Bootstrap framework scope

This branch distributes Bootstrap 4.6.2 and Bootstrap 5.3.8 only as concrete
framework profiles. Other source packages can remain technically analyzable,
but they are not bundled as framework distributions and are not eligible for
productive editor activation.
