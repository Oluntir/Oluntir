# Replaced Assets

## Asset-Korrektur für Version 1.0.0

The duplicated Oluntir logo content previously stored under general illustration and client-logo filenames was removed.

- Real project logos remain only at the established logo paths.
- `assets/images/client/*.svg` now contain seven distinct abstract example marks, each with an existing light variant.
- `assets/images/svg/*.svg` now contain distinct, purpose-neutral Oluntir illustrations.
- Existing filenames and paths were retained; no template references had to be renamed.
- The embedded export asset package was rebuilt from the corrected files.

All replacement graphics are original project assets and are released under the project MIT license.
