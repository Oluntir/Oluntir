# Source Attribution

**Version:** 1.1.0  
**Language:** English  
**Status:** Stable  
**Applies to:** Oluntir 1.1.0  
**Last updated:** 2026-07-29

## Purpose

Records upstream project names, source locations, versions, authorship notices, and required attribution for redistributed third-party material.

## Release requirement

The file must be reviewed together with `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`, and the license texts under `LICENSES/`. Missing or unclear entries block release publication until resolved.
