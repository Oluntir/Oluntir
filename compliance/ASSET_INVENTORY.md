# Asset Inventory

**Version:** 1.2.0  
**Language:** English  
**Status:** Stable  
**Applies to:** Oluntir 1.2.0  
**Last updated:** 2026-07-30

## Purpose

Inventory of redistributed fonts, images, icons, frameworks, scripts, stylesheets, examples, and templates. Each entry should identify path, origin, version where applicable, and license status.

## Release requirement

The file must be reviewed together with `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`, and the license texts under `LICENSES/`. Missing or unclear entries block release publication until resolved.
