# Code of Conduct

**Version:** 1.1.0  
**Language:** English  
**Status:** Stable  
**Applies to:** Oluntir 1.1.0  
**Last updated:** 2026-07-29

Project communication must remain professional and relevant to the technical work.

Participants are expected to:

- discuss code, documentation, tests, and project decisions without personal attacks;
- provide reproducible information for defects;
- respect licensing, attribution, and security-reporting requirements;
- avoid publishing private information or credentials;
- accept maintainer decisions on scope, compatibility, and release readiness.

Reports concerning repository participation may be sent to `info@oluntir.com`. Security issues must follow [SECURITY.md](SECURITY.md).
